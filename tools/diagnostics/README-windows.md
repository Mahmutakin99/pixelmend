# PixelMend bilgisayar testi — Windows

1. `PixelMend-...-Setup.exe` dosyasını kurun ve uygulama açıksa kapatın.
2. Bu klasördeki `PixelMend-Test.cmd` dosyasına çift tıklayın.
3. Önce **Standart test**i, ardından bilgisayar boşta iken **Kapsamlı test**i ayrı çalıştırın. Kapsamlı test 12 lisanslı fotoğraf, 1×/2×/4× büyütme ve büyük görsel işleri içerir; saatler sürebilir.
4. Her koşunun `PixelMend-Test-....zip` dosyasını gönderin. Kapsamlı koşunun görselleri ayrıca insan tarafından incelenmelidir.

ZIP oluşmazsa aynı tarih-saatli ZIP (varsa), kısmi `PixelMend-Test-...` klasörü ve `PixelMend-Test-Baslangic-....txt` dosyasını birlikte gönderin.
