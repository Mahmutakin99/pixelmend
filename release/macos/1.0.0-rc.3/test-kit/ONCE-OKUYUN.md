# PixelMend bilgisayar testi — macOS

Bu paket Apple Silicon Mac (M1/M2/M3/M4 ve sonrası) içindir.

1. DMG dosyasını açın ve PixelMend uygulamasını Applications klasörüne sürükleyin. ZIP alternatifinde arşivi açıp `PixelMend.app` dosyasını Applications klasörüne taşıyın.
2. Açık PixelMend pencerelerini kapatın. Bu klasördeki `PixelMend-Test.command` dosyasına çift tıklayın.
3. Test ekranında **Eksik modelleri indir** kutusunu işaretleyip standart testi başlatın.
4. Bilgisayar boşta iken test penceresini yeniden açıp kapsamlı testi ayrı çalıştırın. Bu koşu 12 lisanslı fotoğrafla çalışır ve uzun sürebilir.
5. Masaüstündeki her iki ZIP raporunu gönderin; kapsamlı test görselleri ayrıca insan tarafından incelenmelidir. ZIP oluşmazsa kısmi rapor klasörünü ve başlangıç raporunu birlikte gönderin.

Bu rc.3 paketi Developer ID ile imzalanmamış ve notarize edilmemiştir. macOS açılışı engellerse Sistem Ayarları → Gizlilik ve Güvenlik bölümünde bu uygulama için gösterilen açma seçeneğini kullanın. Güvenlik ayarlarını genel olarak kapatmayın.

Model dosyaları pakete dahil değildir; uygulama kullanılabilir modelleri indirir ve doğrular. İleri model kartlarının “yakında” olması beklenir. Rapor otomatik gönderilmez.
